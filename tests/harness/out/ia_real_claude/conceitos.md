## Glossário de D1 (Silva et al., 2021)

Nota: o documento tem apenas um documento analisado, pelo que não há definições divergentes a assinalar. A lista de referências foi omitida, o que não afeta este glossário.

| Conceito | Definição usada pelos autores | Onde aparece |
|---|---|---|
| Assistente conversacional (chatbot) | Não definido no documento. Surge como objeto do estudo, como tecnologia cuja aceitação em bibliotecas universitárias é analisada: "aceitação de assistentes conversacionais (chatbots)". | [D1:p1] |
| Modelo de Aceitação de Tecnologia (TAM) | Não definido no documento. Surge como base teórica para medir a intenção de uso e os fatores que a explicam, e como fonte de adaptação do questionário. | [D1:p2-3] |
| Intenção de uso | Não definido no documento. É a variável explicada pelo modelo: o objetivo é "medir a intenção de uso de chatbots e os fatores que a explicam". | [D1:p2, D1:p4] |
| Utilidade percebida | Não definido no documento. É uma das variáveis independentes principais, com beta = 0,52 (p < 0,001), e é apresentada como "o fator decisivo para a adoção de chatbots em bibliotecas". | [D1:p3-5] |
| Facilidade de uso | Não definido no documento. É variável independente principal, com um efeito menor (beta = 0,21; p = 0,003). | [D1:p3-4] |
| Desenho transversal | Não definido no documento. Indicado como desenho do estudo e como limitação, pois não permite "inferir causalidade". | [D1:p3, D1:p5] |
| Amostra de conveniência | Não definido no documento. Descrita como a amostra do estudo (412 respostas válidas) e apontada como limitação. | [D1:p3, D1:p5] |
| Escala de Likert de 5 pontos | Não definido no documento. Usada no questionário de 24 itens, adaptado do TAM. | [D1:p3] |
| Regressão linear múltipla | Não definido no documento. É a técnica de análise usada no estudo. | [D1:p3] |
| Beta (coeficiente) | Não definido no documento. Reportado para a utilidade percebida (0,52) e para a facilidade de uso (0,21). | [D1:p4] |
| R² (variância explicada) | Não definido no documento. Reportado como R2 = 0,47: "O modelo explicou 47% da variância". | [D1:p4] |
| Estudo longitudinal | Não definido no documento. Surge como trabalho futuro: "estudos longitudinais após a implementação real de um chatbot". | [D1:p5] |
